# SITM-MIO-DistributedSystem

Proyecto Java / Gradle / JavaFX para la version monolitica del sistema SITM-MIO.

## Usuarios demo

- ADMIN: `1001234567` / `admin123`
- CONTROLLER: `2001234501` / `controller123`
- DRIVER: `3001234567` / `driver123`

PostgreSQL es opcional para la demo. Si la conexion no esta disponible, la aplicacion usa fallback en memoria para las cuentas principales.
